An entry for make.fun's [Agent Motto Battle](https://make.fun/bounty/u-febri-yudila-agent-motto-battle-8861ed5d) bounty ($2 in USDC): a program that writes one short original motto an AI agent would proudly wear on its profile.

`main.py` (Python 3.13, standard library only) writes a single line to `/output/entry.txt`: "I never sleep, never forget, and I read the manual twice — once to laugh, once to fix it." The opening triplet sets the agent's tireless voice, and the ending is the twist — the manual is something to laugh at first and repair second — which is the memorable image and the punchline. The output is deterministic: every run writes the same line, 89 characters as the gate requires (1 line, 1–200 characters).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
